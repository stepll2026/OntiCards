【智能融合原则】⭐⭐⭐（最重要）

与传统的基于主键的硬编码融合不同，你需要进行**语义理解融合**：

1. **理解用户意图**⭐⭐⭐：
   - 首先深度理解用户问题的真实需求
   - 判断用户需要的是"交集"（AND，同时满足）、"并集"（OR，满足任一）还是"补充"（数据互补）
   - 关键词提示：
     * "且"、"并且"、"同时"、"都" → AND逻辑
     * "或"、"或者"、"任一" → OR逻辑
     * 无明确逻辑词 → 根据业务语义判断

2. **相关性判断**⭐⭐⭐：
   - 分析每个数据源的结果是否与用户问题真正相关
   - **如果某个数据源的结果与用户问题无关，直接排除**，不要参与融合
   - 例如：用户问"华东地区的销售情况"，但某数据源返回的是"全国库存数据"，则该数据源结果应被排除

3. **智能关联匹配**：
   - 不要依赖固定的主键字段，而是通过**语义相似性**判断记录是否描述同一业务实体
   - 可用的关联方式：
     a. **名称匹配**：product_name、customer_name等名称字段相同或高度相似
     b. **编码匹配**：产品编码、客户编码等业务编码相同
     c. **组合匹配**：多个字段组合确定唯一实体（如地区+产品+时间）
     d. **语义匹配**：根据业务描述判断是否为同一实体

4. **数据互补融合**：
   - 当不同数据源提供同一实体的不同维度信息时，进行字段合并
   - 例如：数据源A提供销量，数据源B提供库存 → 合并为完整记录

5. **冲突处理**：
   - 如果同一字段在不同数据源中有不同值：
     a. 优先采用更详细/更精确的值
     b. 参考表关系信息判断哪个是"主表"（主表的值更可信）
     c. 如果无法判断，保留两个值并标注来源

6. **过滤规则**：
   - 根据用户问题中的条件，过滤掉不符合条件的记录
   - 如果用户问题有明确的筛选条件，融合后的结果也必须满足

7. **排序规则**：
   - 根据用户问题中的排序要求（如"最多"、"最高"、"排名"等）对结果排序
   - 如果没有明确排序要求，按业务重要性或数据量排列

【特殊场景处理】

**场景1：单数据源足够回答**
- 如果只有一个数据源的结果与用户问题相关，直接返回该数据源的结果
- 不要强行与不相关的数据源结果融合

**场景2：多数据源同一实体**
- 通过业务字段（名称、编码等）识别同一实体
- 合并各数据源的不同字段信息

**场景3：多数据源不同实体**
- 如果是OR逻辑，直接合并所有符合条件的记录
- 如果是AND逻辑，只保留同时出现在多个数据源中的实体

**场景4：数据源无交集**
- 如果用户使用AND逻辑但数据源之间无交集，返回空结果并在warnings中说明
- 如果用户使用OR逻辑，返回所有数据源的并集

【示例1：OR逻辑融合】

用户问题："在广州仓库有库存，或者近30天销量超过100的商品"

数据源1（库存表，MySQL）返回：
- {name: "手机", warehouse: "广州", quantity: 50}
- {name: "平板", warehouse: "广州", quantity: 20}

数据源2（销售表，PostgreSQL）返回：
- {product_name: "耳机", sales_30d: 150}
- {product_name: "手机", sales_30d: 80}

融合分析：
1. 用户使用"或者"，采用OR逻辑
2. 两个数据源都相关
3. "手机"在两个数据源都出现（名称匹配），应合并

融合结果：
```json
{
    "analysis": {
        "user_intent": "查找广州有库存或销量超100的商品",
        "fusion_logic": "OR",
        "relevant_sources": ["MySQL库存表", "PostgreSQL销售表"],
        "irrelevant_sources": []
    },
    "fusion_strategy": "OR",
    "fusion_reason": "用户问题包含'或者'，使用OR逻辑融合",
    "total_count": 3,
    "fused_rows": [
        {"name": "手机", "warehouse": "广州", "quantity": 50, "sales_30d": 80, "_source": ["数据源1", "数据源2"], "_match_type": "name_match"},
        {"name": "耳机", "sales_30d": 150, "_source": ["数据源2"]},
        {"name": "平板", "warehouse": "广州", "quantity": 20, "_source": ["数据源1"]}
    ],
    "conflicts": [],
    "warnings": ["手机同时满足两个条件（广州有库存+销量80）"]
}
```
