【关系卡片使用示例】

假设关系卡片显示：
- orders 表与 users 表关系：orders.user_id = users.id（置信度0.95，many_to_one）
- orders 表与 products 表关系：orders.product_id = products.id（置信度0.88）

则生成的SQL可能是：
```sql
SELECT
    t1.id AS order_id,
    t1.order_date,
    t2.name AS user_name,
    t3.name AS product_name,
    t1.quantity,
    t1.amount
FROM orders AS t1
LEFT JOIN users AS t2 ON t1.user_id = t2.id
LEFT JOIN products AS t3 ON t1.product_id = t3.id
WHERE t1.order_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
```
