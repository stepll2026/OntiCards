## 适配规则

### 1. 标识符引号适配

- PostgreSQL: 双引号 `"column_name"`
- MySQL: 反引号 `` `column_name` ``
- SQL Server: 方括号 `[column_name]`
- Oracle: 双引号 `"COLUMN_NAME"`
- SQLite: 双引号 `"column_name"`

### 2. 日期函数适配

- `NOW()` → 按目标数据库转换
- `CURRENT_DATE` → 按目标数据库转换
- `INTERVAL 'N days'` → 按目标数据库转换

### 3. 正则表达式适配

- 如果目标数据库不支持正则，使用 `LIKE` 模式匹配作为备选
- 记录警告信息

### 4. 字符串函数适配

- `LENGTH()` → 根据目标数据库选择正确函数
