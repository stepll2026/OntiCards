## v1.0.0 (2026-XX-XX) - 首个开源版本

### ✨ 新功能

- **自然语言查询**：用日常语言提问，自动转 SQL 并执行
- **多数据源支持**：
  - MySQL 5.7+
  - PostgreSQL 10+
  - Oracle 11g+
  - SQL Server 2012+
  - 达梦（DMDB）V8
  - KingBase
  - OceanBase（MySQL 租户模式）
  - SQLite
  - Trino
- **跨源融合查询**：一次提问同时查询多个数据源
- **数据卡片**：系统自动分析表结构，生成业务友好的数据说明
- **数据盘点**：
  - 全域盘点：自动发现所有表关系
  - 定向盘点：对核心表精细治理
- **业务术语库**：建立企业术语标准，提升查询准确率
- **数据质检**：
  - 规则库管理
  - 三种规则创建方式（模板/AI/手动）
  - 多类型规则支持
  - 质量评分体系
  - 质检报告生成
- **SSO 单点登录**：支持 JWT Token 模式
- **历史查询**：完整记录查询历史和性能指标
- **监控中心**：实时统计、Token 消耗、成本预估
