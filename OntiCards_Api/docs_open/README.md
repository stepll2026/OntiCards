## 一、项目简介

**OntiCards 是一款面向企业的"AI 数据中枢"，围绕业务数据库提供从连接、理解到查询、质检、监控的一体化能力。**

它不是单纯的 NL2SQL 工具，而是一个**融合了智能查询、数据理解、数据质检、查询监控和数据资产管理的完整平台**：

- 通过**智能数据卡片**理解业务语义
- 通过**数据盘点与关系卡片**建立表间关系
- 通过**业务术语库**统一企业语言
- 通过**自然语言查询**让业务人员自助取数
- 通过**跨源融合**打破数据孤岛
- 通过**数据质检**保障数据健康
- 通过**历史查询与监控中心**实现查询审计与运营分析
- 通过**用户体系、API Key、SSO** 等能力支撑企业级集成与治理

**一句话概括**：OntiCards 让企业数据库从"只能写 SQL 才能用"变成"会说业务话就能查、能检、能管、能审计"。

## 二、快速开始

### 2.1 环境要求

- Docker 和 Docker Compose
- 2 核 CPU / 4GB 内存（最低）
- PostgreSQL 10+（系统数据库）

### 2.2 快速部署

```bash
# 1. 克隆项目
git clone https://github.com/your-org/onticards.git
cd onticards

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填写必要配置

# 3. 一键启动
docker-compose up -d

# 4. 访问系统
# 浏览器打开 http://localhost:3000
```

详细步骤请参考：[部署指南](docs_open/部署指南.md)

### 2.3 5 分钟快速体验


| 阶段        | 操作                                         |
| --------- | ------------------------------------------ |
| **基础配置**  | 登录系统，配置模型信息                                |
| **数据接入**  | 添加第一个数据源                                   |
| **数据理解**  | 等待数据卡片生成，补充业务说明（可选：手动调整或上传字典文件），执行盘点，建立术语库 |
| **智能查询**  | 输入自然语言问题，查看数据结果                            |
| **历史查询**  | 查看查询记录、Token 消耗                            |
| **盘点与质检** | 执行盘点建立关系，创建质检规则并执行                         |
| **监控中心**  | 查看实时查询量、QPS、性能分析（管理员）                      |
| **开放集成**  | 创建 API Key 集成取数能力或通过 SSO JWT 模式打通用户体系      |

## 五、核心功能详解

### 5.1 数据接入

- **多数据源支持**：MySQL、PostgreSQL、Oracle、达梦、KingBase、OceanBase、SQL Server、SQLite、Trino 等
- **自动解析**：识别表结构、字段类型、索引、外键
- **健康监控**：连接状态、响应时间、错误率定期巡检
- **增量同步**：MD5 指纹识别结构变更

### 5.2 智能数据卡片

- **业务化卡片**：为每张表/字段生成"业务说明书"
- **字段画像**：采样分析值域分布、识别枚举类型
- **敏感字段识别**：三层级自动识别，过滤后再送大模型
- **字典补充**：支持上传文件批量补全字段说明

### 5.3 数据盘点

- **全域盘点**：一键自动发现所有表间关系，支持跨数据源
- **定向盘点**：人工 + AI 推荐的精细化盘点
- **关系卡片**：结构化存储 JOIN 条件、关系类型、置信度

### 5.4 自然语言查询

- **多步推理**：意图识别 → 语义检索 → 表关系分析 → SQL 生成 → 安全校验 → 执行
- **多方言适配**：自动适配 MySQL、Oracle、PostgreSQL、达梦、KingBase、OceanBase 等
- **智能容错**：字段不存在、跨库不一致、术语模糊等场景自动降级
- **术语展开**：自动识别并展开"高价值客户""核心商品"等业务术语

### 5.5 跨源融合

- **一次提问多源查询**：自动识别涉及的数据源
- **多策略融合**：支持交集、并集、汇总等结果整合
- **跨库对齐**：自动处理跨库字段差异

### 5.6 业务术语库

- **统一企业语言**：术语 + 同义词 + 关联字段，跨数据源关联
- **智能匹配**：查询时自动识别并展开术语含义
- **数据源绑定**：可为不同数据源绑定专属术语库

### 5.7 数据质检

- **规则库**：模板/AI/手动三种规则创建方式
- **多类型规则**：非空、唯一性、格式、范围、枚举、正则、跨表比对、自定义 SQL
- **量化评分**：优秀/良好/一般/较差/差五档评分，生成质检报告

### 5.8 用户与权限

- **用户级数据源隔离**：每位用户只能访问自己添加的数据源
- **角色控制**：普通用户 / 管理员 / 审计员
- **敏感字段脱敏**：查询结果自动脱敏
- **操作审计**：完整的查询、配置、登录日志

### 5.9 API Key 与 SSO

- **API Key 认证**：支持 `Authorization`、`Bearer Token`、`X-API-Key` 三种方式
- **SSO 单点登录**：JWT Token 模式对接企业身份认证
- **双认证接口**：登录态与 APIKey 接口功能完全一致

### 5.10 历史查询与监控

- **历史查询**：完整记录查询明细、性能指标、Token 消耗
- **监控中心**：实时查询量、QPS、错误告警、Token 消耗、成本预估
- **性能分析**：向量检索/SQL 生成/SQL 执行各环节耗时分析、慢查询 TOP
