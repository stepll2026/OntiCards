101 104

广州仓库库存（数量≤5）的商品及其价格？

外设类在深圳仓有库存的商品有哪些？
103

充电宝在广州还有多少库存？

103

价格低于150，且近30天销量大于100的商品有哪些？
103

在广州仓库有库存，或者近30天销量超过100的商品有哪些？
101 102 103 104 105

---------------------场景：学校---------------------

（1）用例1：计算机学院 + 秋季课程的教室与时间

问题：
“列出计算机学院在秋季学期开设的课程、任课教师、教室与上课时间（按课程名排序）。”

正确结果（2 行）：

course_name	teacher	classroom	weekday	start_time	end_time
数据结构	李伟	实验楼B201	周二	10:00	11:30
数据结构	李伟	实验楼B203	周五	13:00	14:30

说明：计算机学院里秋季仅有《数据结构》（李伟），且有两条上课记录。

（2）用例2：每位老师授课总学分

问题：
“统计每位老师所授课程的总学分（按姓名排序）。”

正确结果（4 行）：

name	total_credits
张强	3
李伟	7
王芳	3
赵敏	4

计算：李伟=《数据结构》4 +《数据库原理》3 = 7；其余见课程表。

（3）用例3：周二上课的课程与教师

问题：
“找出周二有课的课程、任课教师及教室与时间。”

正确结果（1 行）：

course_name	teacher	classroom	weekday	start_time	end_time
数据结构	李伟	实验楼B201	周二	10:00	11:30

（4）用例4：教室名称包含“实验”的所有课程

问题：
“列出教室名称包含**‘实验’**的所有课程（课程名、教室、星期，按星期/课程名排序）。”

正确结果（3 行）：

course_name	classroom	weekday
数据结构	实验楼B201	周二
操作系统	实验楼B202	周四
数据结构	实验楼B203	周五


（5）用例5：每门课最新一次上课的教室与时间
